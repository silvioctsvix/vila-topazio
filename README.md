# Vila Topázio — dossiê de viabilidade

Site estático para avaliação de aquisição do imóvel Caixa nº 878770707802-8, apartamento 302, bloco 13, Vila Bethânia, Viana/ES.

## Publicar com GitHub Pages
1. Em **Settings → General → Danger Zone → Change repository visibility**, altere a visibilidade para **Public**, caso deseje compartilhar livremente.
2. Em **Settings → Pages**, em **Build and deployment**, selecione **Deploy from a branch**.
3. Configure **main** e **/(root)** e clique em **Save**.
4. Aguarde a publicação e acesse: https://silvioctsvix.github.io/vila-topazio/
